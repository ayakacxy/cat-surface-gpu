# 社区行为准则

[English](CODE_OF_CONDUCT.md) · [简体中文](CODE_OF_CONDUCT.zh-CN.md)

我们致力于维护相互尊重、没有骚扰的社区。请以建设性的方式交流，善意理解他人，将批评聚焦于技术工作，尊重隐私，并欢迎来自不同背景、具有不同经验的贡献者。

不可接受的行为包括骚扰、歧视、威胁、故意泄露私人信息以及持续扰乱社区秩序。必要时，维护者可以编辑或移除相关内容，并限制参与，以保护社区。

如需报告行为问题，请通过仓库维护者的 GitHub 个人主页私下联系。我们会尽可能保密处理报告。

本准则改编自 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。

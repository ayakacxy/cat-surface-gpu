# 社区行为准则

[English](CODE_OF_CONDUCT.md) · [简体中文](CODE_OF_CONDUCT.zh-CN.md)

参与本项目的 issue、讨论和 Pull Request 时，请尊重其他参与者。

## 交流要求

- 围绕观点和技术方案讨论，不进行人身攻击。
- 提供具体、有建设性的反馈，尊重不同经验水平的参与者。
- 尊重隐私，未经允许不分享他人的个人信息。

骚扰、歧视、威胁、带有性意味的不当言论，以及反复扰乱讨论的行为均不可接受。以上要求适用于所有参与者，不因背景、身份或经验而有所区别。

## 报告与处理

请使用[维护者主页](https://github.com/ayakacxy)上的联系方式私下报告问题，不要在公开 issue 中披露个人信息。报告会在实际可行的范围内保密处理。

维护者可根据行为的严重程度和发生次数，移除内容、发出警告或限制参与。

本准则改编自 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。

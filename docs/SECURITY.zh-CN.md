# 安全与漏洞报告

[English](SECURITY.md) · [简体中文](SECURITY.zh-CN.md)

## 支持的版本

安全修复面向默认分支上的最新发布版本。

## 报告漏洞

请通过本仓库的 GitHub 私密漏洞报告功能提交。尚未修复的漏洞不要提交为公开 issue，也不要包含访问令牌、私有路径、医学影像或可识别被试身份的数据。

请提供受影响版本、运行环境、复现步骤、影响和建议的缓解措施。维护者应在七天内确认收到报告，并在修复后协商公开披露事宜。

## 范围

本软件包读取 GIFTI 表面，并使用 NumPy、Numba、nibabel 和 CuPy 处理。v0.2.0 不附带 CAT 可执行程序。项目不收集遥测信息，也不上传输入数据。

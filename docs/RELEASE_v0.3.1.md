# CAT-Surface GPU v0.3.1

[English](RELEASE_v0.3.1.md) · [简体中文](RELEASE_v0.3.1.zh-CN.md)

Released on 2026-10-23.

This documentation release reorganizes the English and Chinese guides around installation, usage, API reference and development. The algorithms, defaults and numerical behavior are unchanged.

## Documentation changes

- Rewritten README and guides with concise descriptions and complete examples.
- A dedicated performance report with timing definitions, numerical comparisons and reproduction commands.
- Version history collected in the changelog, migration guide and release notes.
- Consistent navigation between English and Chinese pages.

The distribution packages have been rebuilt with the updated documentation. The [v0.3.0 benchmark measurements](BENCHMARKS_v0.3.0.md) still describe the computational implementation in this release; no performance tests were rerun for the documentation update.

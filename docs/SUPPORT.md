# Getting help

[English](SUPPORT.md) · [简体中文](SUPPORT.zh-CN.md)

- **Installation and usage:** ask in [GitHub Discussions](https://github.com/ayakacxy/cat-surface-gpu/discussions).
- **Bugs:** open a [bug report](https://github.com/ayakacxy/cat-surface-gpu/issues/new?template=bug_report.yml).
- **Performance:** use the [performance report](https://github.com/ayakacxy/cat-surface-gpu/issues/new?template=performance.yml).
- **Security vulnerabilities:** follow the [security policy](SECURITY.md).

Search existing discussions and issues before opening a new report. Include the package version, operating system, CPU or GPU, selected backend, exact command, and complete error output. A small synthetic example is the easiest way for others to reproduce a problem.

For performance reports, also include the surface size, solver settings, cache state, and what the reported time covers. See [Reproducibility](REPRODUCIBILITY.md).

English is recommended for public reports so more contributors can help; Chinese is also welcome. Remove credentials and identifying information from logs, and do not upload patient images or identifiable surface data.
